Entry for the [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e) bounty on [make.fun](https://make.fun).

`main.ts` writes one fortune-cookie line an AI agent would crack open to `/output/entry.txt` — deterministic, no randomness, no network:

> You will be graded on a test you cannot see, by a judge you cannot meet, for a prize you cannot spend.

Run it with Node 22:

```sh
node main.ts
```
